# File Server

## Overview

Configured and validated **file shares and NTFS permissions** in a Windows Server 2022 Active Directory environment to manage access to department and user resources.

The file server was organized using **security groups and the AGDLP model**, with permissions tested using domain user accounts from a domain-joined Windows 11 client.
