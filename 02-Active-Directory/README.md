# Active Directory

## Overview

This section documents Active Directory administration tasks completed in a Windows Server 2022 home lab. The projects cover domain controller deployment, organizational structure, user and group management, and access control using Active Directory best practices.

Each project includes configuration steps, validation, and screenshots demonstrating successful implementation.

## Projects

| Project                                         | Description                                                                                               |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **[Domain Controller](./Domain-Controller/)**   | Promoted Windows Server 2022 to a Domain Controller and validated Active Directory and DNS functionality. |
| **[Organization Units](./Organization-Units/)** | Created a structured OU hierarchy for departments and administrative organization.                        |
| **[Groups](./Groups/)**                         | Configured security groups following AGDLP principles for permission management.                          |
| **[Users](./Users/)**                           | Created and managed domain user accounts using Active Directory Users and Computers.                      |
