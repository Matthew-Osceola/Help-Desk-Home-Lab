# Help Desk Tickets

## Overview

Documented simulated Tier 1 help desk tickets in a Windows Server 2022 Active Directory environment. Each ticket follows a realistic troubleshooting workflow, including investigation, resolution, validation, and supporting screenshots.

## Tickets

| Ticket                                                                | Description                                                                                          |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **[Password Reset](./Ticket-01-Password-Reset)**                      | Reset a user's password in Active Directory and verified successful sign-in.                         |
| **[Account Lockout](./Ticket-02-Account-Lockout)**                    | Unlocked a user account after a Group Policy account lockout and confirmed access was restored.      |
| **[Mapped Network Drive](./Ticket-03-Map-Network-Drive)**             | Troubleshot a missing mapped network drive and verified Group Policy applied successfully.           |
| **[Folder Permission Issue](./Ticket-04-Folder-Permission-Issue)**    | Resolved a department folder access issue by verifying group membership and NTFS permissions.        |
| **[DHCP No IP Address](./Ticket-05-DHCP-No-IP-Address)**              | Restored client network connectivity by renewing a DHCP lease and verifying the assigned IP address. |
| **[DNS Name Resolution](./Ticket-06-DNS-Name-Resolution)**            | Troubleshot a DNS resolution issue using `nslookup` and validated the DNS server configuration.      |
| **[Windows Firewall Access](./Ticket-07-Windows-Firewall-Access)**    | Verified Windows Firewall policies applied through Group Policy and confirmed network connectivity.  |
| **[Windows Updates (Action1)](./Ticket-08-Windows-Updates-Action1)**  | Deployed Windows updates with Action1 and verified successful installation and compliance.           |
