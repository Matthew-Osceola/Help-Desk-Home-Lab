# Help Desk Tickets

## Overview

Documented simulated Tier 1 help desk tickets in a Windows Server 2022 Active Directory environment. Each ticket follows a realistic troubleshooting workflow, including investigation, resolution, validation, and supporting screenshots.

## Tickets

### Password Reset

Reset a user's password in Active Directory and verified successful sign-in.

### Account Lockout

Unlocked a user account after a Group Policy account lockout and confirmed access was restored.

### Mapped Network Drive

Troubleshot a missing mapped network drive and verified Group Policy applied successfully.

### Folder Permission Issue

Resolved a department folder access issue by verifying group membership and NTFS permissions.

### DHCP No IP Address

Restored client network connectivity by renewing a DHCP lease and verifying the assigned IP address.

### DNS Name Resolution

Troubleshot a DNS resolution issue using `nslookup` and validated the DNS server configuration.

### Windows Firewall Access

Verified Windows Firewall policies applied through Group Policy and confirmed network connectivity.

### Windows Updates (Action1)

Deployed Windows updates with Action1 and verified successful installation and compliance.
