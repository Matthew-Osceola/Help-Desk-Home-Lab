# Troubleshooting

## Overview

Documented real troubleshooting scenarios encountered while building and validating a Windows Server 2022 Active Directory homelab.

Each scenario includes the symptoms, investigation, resolution, validation, and supporting screenshots to demonstrate systematic troubleshooting and problem-solving.

## Troubleshooting Scenarios

| Scenario                                                                   | Description                                                                                                                  |
|--------------------------------------------------------------------------- | -----------------------------------------------------------------------------------------------------------------------------|
| **[DHCP Troubleshooting](./DHCP-Troubleshooting)**                         | Diagnosed a client IP assignment issue by verifying the DHCP scope, renewing the lease, and validating network connectivity. |
| **[DNS Troubleshooting](./DNS-Troubleshooting)**                           | Resolved name resolution issues using `nslookup`, DNS Manager, and DNS record validation.                                    |
| **[Group Policy Troubleshooting](./Group-Policy-Troubleshooting)**         | Investigated Group Policy application issues using `gpupdate`, `gpresult`, and policy validation.                            |
| **[NTFS Permissions Troubleshooting](./NTFS-Permissions-Troubleshooting)** | Diagnosed folder access problems by verifying group membership, inheritance, and NTFS permissions.                           |
